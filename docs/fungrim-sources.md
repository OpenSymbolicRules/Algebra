# Fungrim sources

The logarithm rule `exp(ln(z)) = z` is an independent OSR encoding of Fungrim
MathJSON corpus entry `d87f6e`. Fungrim states the required condition
`z ∈ ℂ \\ {0}`; the OSR rule preserves it as `NonzeroQ(z)`.

The converse direction is intentionally absent: the principal natural
logarithm does not satisfy `ln(exp(z)) = z` for every complex `z`.
